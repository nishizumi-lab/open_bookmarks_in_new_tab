プライバシーポリシー (Privacy Policy)

最終更新日: 2026年11月1日

Chrome拡張機能「ブックマークを新しいタブで開く (Open Bookmarks in New Tab)」（以下、「本拡張機能」）は、利用者のプライバシー保護を最優先事項として設計されています。本方針では、本拡張機能におけるデータ等の取扱いについて定めます。

1. ユーザーデータの収集および送信

本拡張機能は、ユーザーの個人情報、閲覧履歴、ブックマーク情報、アクセス先URL、入力データなどを外部サーバーへ収集、保存、共有、または送信することは一切ありません。すべての処理は利用者のブラウザ（ローカル環境）内でのみ完結して実行されます。

2. 使用する権限とその用途

要求する権限 利用目的
webNavigation ブックマーク経由の画面遷移（transitionType: auto_bookmark）を検知し、新規タブでの展開をトリガーするために使用します。閲覧履歴の収集や外部送信は行いません。
tabs ブックマーク先URLを新しいタブとして生成し、元のタブを直前のWebページへ復帰させる制御を行うために使用します。
bookmarks ポップアップ画面内においてブックマーク一覧を表示・検索し、選択したブックマークを新規タブで開くために使用します。
storage 拡張機能の有効化・無効化状態、および新規タブの展開方法（フォアグラウンド/バックグラウンド）の設定値を端末内に保持・同期するために使用します。

3. 第三者への開示

本拡張機能は、いかなるデータも第三者（広告ネットワーク、アナリティクス事業者、データブローカー等）に提供、共有、または販売することはありません。

4. リモートコードの不使用

本拡張機能は外部サーバーから動的に読み込まれるスクリプト（リモートコード）を一切使用していません。すべての実行可能コードは拡張機能パッケージ内に同梱されています。

5. お問い合わせ

本拡張機能に関するお問い合わせは、GitHubリポジトリのIssuesよりご連絡ください。
