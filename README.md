# ブックマークを新しいタブで開く (Open Bookmarks in New Tab)

Chromeのブックマークをクリックした際に、現在閲覧中のタブを上書きせず、自動的に新しいタブで開くManifest V3対応のブラウザ拡張機能です。

## 主な機能
- ブックマークバーやブックマークメニューからのクリックを検知し、自動的に新しいタブで開きます。
- 既存の閲覧ページやフォーム入力中の状態を保持したままブックマーク先を参照できます。
- 空白の新規タブ（chrome://newtab/）でクリックした場合は、不要な空タブを残さずそのタブ内で開きます。
- ポップアップ画面から機能の有効・無効切り替えや、バックグラウンドでのタブ展開設定が可能です。
- ポップアップ内からブックマークをインクリメンタル検索して直接新しいタブで開くことができます。

## プライバシーポリシー (Privacy Policy)

### 1. ユーザーデータの収集および利用について
本拡張機能は、ユーザーの個人情報、閲覧履歴、ブックマーク情報、アクセスログなどのデータを外部サーバーへ収集、保存、送信、または追跡することは一切行いません。すべての処理はユーザーの端末（ブラウザ内）でのみローカルに完結します。

### 2. 使用する権限と利用目的
本拡張機能が要求する権限およびその利用目的は以下の通りです。
- webNavigation: ブックマークからのページ遷移（transitionType: auto_bookmark）を検知し、新規タブの展開処理を開始するために使用します。閲覧履歴の収集や外部送信は行いません。
- tabs: ブックマーク先のURLを新しいタブで生成し、元のタブを直前のWebページへ戻す制御を行うために使用します。
- bookmarks: ポップアップ画面においてブックマーク一覧を表示・検索し、選択したブックマークを新規タブで開くために使用します。
- storage: 拡張機能のオン/オフ設定およびタブ展開オプション（バックグラウンド展開の有無）をブラウザ内に保存・同期するために使用します。

### 3. 第三者へのデータ提供
本拡張機能は、いかなるユーザーデータも第三者と共有、販売、または提供することはありません。

### 4. リモートコードの不使用
本拡張機能は、外部サーバーから動的に読み込まれるスクリプト（リモートコード）を一切使用していません。すべてのソースコードは拡張機能パッケージ内に同梱されています。
